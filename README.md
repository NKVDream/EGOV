# EGOV
1.1 анализ предметной области:
приложение по типу wiki, в котором содержится описание тех или иных систем от электронного правительства.

Бизнес процессы: Создание статей - админ пишет статью по ситеме. Редактирование и удаление статей - админ может удалять и редактировать статьи.
Просмотр статей - рядовой пользователь может только просматривать статьи. 

1.2 Определить сущности и выделить атрибуты:

1) Пользователь (Никнейм, электронный адрес почты, роль) - в зависимости от роли может совершать определенные действия
2) Роль(Название, описание) - позволяет определить уровень доступа
3) Статья(Згаловок, содержание, дата публекации, дата последней обновления, автор) - основная сущноть приложения
4) Систеа(Название системы, краткое описание) - определяет к какому ведомству или сервису относится статья
5) История изменений(Тот кто изменил, старый текст, дата изменения)
